What changed, and why nothing was lost
Every pane opens with one 40px heading row — vault name, active folder name, note title — all 15px/600 on the same #eef0f2 band, actions right-aligned. The tree's New / Rename / Delete became 26px icon buttons inside that row (tooltips + right-click keep them discoverable). The tree's root row no longer repeats the vault name: it reads "ALL FOLDERS" in small caps and still collapses everything, so the heading owns the vault identity.
Notes and reader share a 28px footer. The notes count, sort and Tasks filter live there — the header no longer carries a second sort control, so "⇅ Modified" in the footer is the single sort affordance (click opens the sort menu), and the header is free for the collapsing search field (⌘F expands it in place over the heading). The reader footer shows the read-only warning when there is one and the file path when there isn't (toggle it in Tweaks). Insert — an editor command menu (image, attachment, table, divider) — moved out of the heading into that footer beside Actions, and appears only when the note is editable; the heading stays purely identity plus ⋯.
One button language throughout: transparent by default, grey fill and 1px border on hover, icon-only where the glyph is unambiguous, icon + label where it isn't. Shades: panes #f5f6f7, header/footer bands #eef0f2, dividers #dcdfe3, text #1e2226, secondary #6b7280, muted #8b9299, links and tags #2563c9. Weights: 600 headings and note titles, 500 labelled buttons, 400 everything else — no other weights.
